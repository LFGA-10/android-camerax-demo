# Android CameraX Premium Demo 📸

A high-performance Android application demonstrating the power of **Jetpack CameraX** combined with **Jetpack Compose**.

![Camera Preview](https://images.unsplash.com/photo-1516035069371-29a1b244cc32?auto=format&fit=crop&q=80&w=1000)

## ✨ Features
- **Real-time Preview**: Low-latency camera preview using CameraX ViewPort.
- **Compose-based UI**: Modern, declarative UI built with Jetpack Compose.
- **Lifecycle Awareness**: Automatically handles camera binding/unbinding with Android lifecycle.
- **Permission Handling**: Seamless runtime permission requests.
- **High Extensibility**: Structured for adding Image Analysis and Video Capture.

## 🚀 Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Camera API**: Jetpack CameraX
- **Build System**: Gradle (Kotlin DSL)

## 🛠️ Getting Started
1. Open this project in **Android Studio**.
2. Sync Gradle files.
3. Run on a physical device (Camera is required).
